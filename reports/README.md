---

## 📄 À quoi sert ce dossier ? / What is this folder for?

> 🇬🇧 A pentest report is a professional document that summarizes the findings of a security assessment. It includes identified vulnerabilities, their severity, and remediation recommendations. Writing reports is a key skill for any security professional.
>
> 🇫🇷 Un rapport de pentest est un document professionnel qui résume les résultats d'un audit de sécurité. Il inclut les vulnérabilités identifiées, leur criticité, et des recommandations de remédiation. La rédaction de rapports est une compétence clé pour tout professionnel de la sécurité.

---

## 📁 Structure d'un rapport / Report Structure

Chaque rapport suit la structure suivante / Each report follows this structure :

```
reports/
└── nom-de-la-cible.md
    ├── Résumé exécutif / Executive Summary
    ├── Méthodologie / Methodology
    ├── Vulnérabilités identifiées / Identified Vulnerabilities
    │   ├── Criticité / Severity (Critical / High / Medium / Low)
    │   ├── Description
    │   ├── Preuve / Proof of Concept
    │   └── Recommandations / Recommendations
    └── Conclusion
```
